# OSF Settings branding

Sage-green member of the OSF family: OSF Animation is amber (playback curve), OSF UI is teal
(nested frames), OSF Settings is sage green (stacked setting tracks). Geometry, ring, arc text,
stars and type are shared with the siblings; only the accent and the centre emblem change.

| File | Use |
| --- | --- |
| `osf-settings-header.*` | 1600×520 Nexus header / top-of-page banner |
| `osf-settings-patch.*` | 1024 mission patch with wordmark (mod page thumbnail / avatar) |
| `osf-settings-patch-emblem.*` | 1024 patch, emblem only (square thumbnail, GitHub social) |
| `osf-settings-emblem.*` | 512 transparent mark alone |

The SVGs are the source of record. `../section-headers/svg/` holds the section-header sources; the
`.png`s beside them are 2× (2600×260), like OSF Animation's.

## Fonts

Sources name Bahnschrift first (same as the siblings). The header and both patch PNGs were
re-rasterized on Windows in Bahnschrift (headless Edge, native size, transparent background). The
emblem PNG was rendered off-Windows with Barlow Semi Condensed standing in, but it has no text.
